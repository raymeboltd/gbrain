# Pure local text-space contract

This module is stage 1 only. It performs no queries, filesystem reads, configuration changes, provider requests or activation. Existing engine, gateway and CLI paths remain unchanged. `resolveEmbeddingContext(undefined)` returns null; only explicit `strict: true` constructs this new contract.

`descriptor.ts` reuses native `ResolvedColumn` and recipe/model resolution. The initial allowlist is BGE-M3 with native ollama, llama-server or lmstudio, exactly1024 dimensions. Storage identifiers are code-owned: separate vector/timestamp/hash/signature columns on chunks/facts/takes and a separate query-cache table. No descriptor field can replace legacy storage or inject an identifier. These identifiers are a proposed stage-2 schema contract; this module does not create them. Legacy model, timestamp and content-hash columns must remain unchanged during target-only writes.

The descriptor fixes transport to loopback-only, redirect:error and fallback:none. URL validation is pure: it does not resolve localhost, inspect a running model, validate model weights or enforce an HTTP client's redirects. The stage-2 transport must pin actual connections to loopback, reject redirects/remote fallbacks and verify the served model/shape before sending admitted content. Recipe dimension0 means native metadata does not declare a width; the fixed BGE-M3 contract still requires1024. A space signature binds model/dimensions/endpoint; scope changes do not alter it.

`eligibility.ts` constructs a deeply frozen context from brain ID, scope revision, manifest SHA256, acceptance-receipt SHA256 and exact content bindings. Each binding includes lane, source ID, record ID, page ID, accepted input SHA256 and page generation. IDs/generation are lossless decimal strings. Facts additionally require independently resolved canonical and entity page IDs to agree with the admitted page; unknown/conflicting identity refuses. Conflicting record/source, page-source or generation grants invalidate the entire scope. Explicit denied pages cannot coexist with grants. Empty membership denies all.

This is validation, NOT grant authentication. The trusted front door must verify the accepted manifest and receipt against their authoritative bytes and actual authorization before constructing a context. A caller-supplied hash or a prior full-read ledger is not an authorization. Filesystem authoring hashes cannot substitute for DB embedding-input hashes. The cache namespace includes exact normalized membership, scope hashes/revision, brain and descriptor, so changing membership cannot collide merely by reusing a claimed manifest hash.

`admitsContent` is for already obtained metadata, never a post-filter for a broad content SELECT. `assertScopeBinding` requires the owning brain and refreshed scope revision/hash; the caller obtains that refresh without content reads. The factory's process-local identity guard prevents forged structural copies from being consumed by these functions, but does not authenticate whoever called the factory.

`eligibilityPredicate(context, brainId, lane, firstParameter)` returns a parenthesized SQL predicate and flat string parameters. Only the fixed alias `candidate` appears in SQL. The engine adapter supplies a metadata relation with columns:

- source_id, record_id, page_id, input_hash, page_generation;
- for facts, canonical_page_id and entity_page_id.

These are adapter projections, not newly assumed columns on existing tables. The same predicate must constrain the SELECT that projects bodies/claims; adapters must additionally apply native source/lifecycle/visibility/pending rules before projection. Never interpolate parameter values or accept a caller-provided alias/table. The parameter offset is explicit and PostgreSQL's parameter limit is enforced. Empty lanes compile FALSE. Stage 2 must prove SQL parity on PG and PGLite, including NULL owner/hash/generation refusal, before connecting this seam to a content query.

Cache rows do not have content grants in this first contract. Use cacheNamespace plus normal mode/source knobs and revalidate every referenced page's eligibility before reading a payload. Scope revision changes require dispatch drain/cancellation before publication: a CAS after a provider request cannot unsend data already dispatched. No fallback to legacy vectors/cache/provider is allowed in strict mode.

Stage-2 obligations: additive schema and metadata-only prepare; authenticated policy loading; engine metadata projections and vector-only CAS writes; eligible content selection; provider transport enforcement; cache namespace/freshness; all inline/backfill/query consumers; both-engine negative tests. Do not activate when only the chunk lane works. Rollback disables target dispatch/read access and returns to keyword-only while preserving legacy and target artifacts. Preserving vectors during embedding-only operations does not promise historical vector retention after arbitrary canonical chunk deletion.
